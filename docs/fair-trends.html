Method and definitions

How this is measured

One point per assessment run. Every monthly run of the self-hosted F-UJI server appends a dated snapshot to fair-history.jsonl — per DOI: the total, the F/A/I/R split, and each metric’s earned score and verdict. This page reads the per-run aggregates. Each point is a measurement on a known date, and each change shown is movement since the previous run. The same DOIs are re-measured every run, so movement reflects changed metadata; where the number of DOIs differs between two runs, part of the movement comes from records joining or leaving, and that change is shown without colour beside the counts.

What is assessed. Every dataset DOI in the registry. PhysicalObject sample records are excluded — F-UJI’s metrics target data resources.

Comparability. Scores are comparable only within one metric version (pinned v0.8: 17 metrics, 26 points). The signal is movement, not level.

Averages weight each assessed DOI equally.

When a source fails. The history feed is the only thing this page reads. If it does not answer, a red banner says so and every figure renders as “—” with the reason attached. No number on this page is ever produced by a failed request — a missing measurement and a measured zero are different facts, and they are drawn differently.
