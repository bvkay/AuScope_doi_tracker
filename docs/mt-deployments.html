Reading these numbers

  1. Single source of truth. Deployment figures come only from AusMT per-station runs records. The instrument registry’s field-survey DOIs (coverage windows, component lists) are deliberately not used for deployment accounting — they remain as PID-graph links.
  2. Coverage grows as runs are populated. — Every figure on this page grows as AusMT metadata is populated — the register is a floor, not a ceiling.
  3. Hours measure acquisition, not campaign commitment. An instrument’s recording-hours exclude transport, setup and idle time between stations, so these are conservative utilisation figures.
  4. Scope: AuScope-funded instruments (DataCite fundingReferences). Instruments without an AuScope funding tag are excluded from all totals here.
  5. Electrodes are invisible. Electric-channel hardware carries no identifiers in the source metadata, so only recorders and magnetic coils are countable.
  6. Whole models still wait on runs metadata. An instrument whose surveys have no populated runs block does not appear here at all — a metadata backlog, not idle hardware. Each survey enters the register automatically once populated.

Sources. Run records: ausmt.auscope.org.au /data/products/<survey>/<station>/station.json — snapshot fetched — (feed ausmt-data.json, regenerated weekly by src/ausmt-inventory.js; upstream build —). Fleet scope: DataCite instrument registry, prefix 10.82388, AuScope-funded units via fundingReferences.

Method. One occupation = one instrument (recorder or coil) at one station for one run’s time_period. Recording-hours sum the acquisition windows; days are hours ÷ 24. Every figure is recomputed from the feed at page load — nothing on this page is hand-entered. Explore: Impact overview · Instrument Registry · AusMT Portal
