How these numbers are made

Harvest. On — the NVCL pipeline queried every participating node’s public services: the WFS gsmlp:BoreholeView layer (filtered to nvclCollection='true') for registered boreholes, then each node’s NVCLDataServices getDatasetCollection for every borehole’s dataset records. Nothing on this page comes from a private database — the same services are public, and the Live check button and source links query them directly.

Scanned km. The scanned interval (start–end depth) of each HyLogger dataset, summed. This is core imaged by a spectral scanner, which differs from metres drilled — the same holes total — km drilled.

Instruments. HyLogger units are identified from instrument fields in dataset metadata (— of — datasets carry instrument data). — boreholes hold more than one scan (up to —).

Live check. Your browser fetches each node’s WFS resultType=hits URL — the same endpoints cited in the Verify column — and reads numberMatched from the XML. Some government servers do not send CORS headers, so a browser fetch can be blocked even while the service is up; the source link always works because it opens the server’s answer directly.
