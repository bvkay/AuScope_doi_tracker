Networks

One row per network epoch — a reused FDSN code (1G, 1H, 2B, 7M, WG) appears once per experiment. Click a row for station epochs, instrumentation, network comments and the raw StationXML. The DOI column shows the <Identifier type="DOI"> element embedded in the network metadata; the FDSN registry may hold a DOI even where none is embedded (the registry sends no CORS headers, so it cannot be queried from this page).

Instrument inventory

Every sensor and digitiser in the service's channel metadata, grouped by model and serial number, with each unit's deployment history: network, station, channels recorded, and operating epoch. Building the inventory requires the channel-level metadata of every network epoch (one request each, typically under a minute). Units without a usable serial number cannot be told apart or tracked between deployments; they are grouped by model at the end of the table.
